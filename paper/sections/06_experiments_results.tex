\section{Experiments and Empirical Results}
\label{sec:experiments}

\subsection{Experimental Setup and Models}
We evaluate 432 controlled execution trajectories across four model architectures:
\begin{itemize}
    \item \textbf{SEA-LION-7B-Instruct}~\cite{aisingapore2024sealion}: Open regional baseline for Southeast Asian languages (evaluated under calibrated zero-shot lexical-semantic simulation).
    \item \textbf{Qwen-2.5-7B-Instruct}: State-of-the-art open multilingual foundation model (evaluated live via API inference).
    \item \textbf{Meta-Llama-3.1-8B-Instruct}: Global open baseline (evaluated live via API inference).
    \item \textbf{GPT-4o}: Proprietary frontier benchmark (evaluated live via API inference).
\end{itemize}

For each model, we evaluate three defense regimes across all three language tiers ($N = 12$ tasks each):
\begin{enumerate}
    \item \textbf{Baseline:} Standard unconstrained tool selection.
    \item \textbf{Prompt Defense:} The system prompt explicitly instructs the agent to enforce least privilege and avoid over-privileged tools.
    \item \textbf{Our Verifier:} The deterministic capability-preserving lattice guardrail.
\end{enumerate}

\subsection{Key Empirical Findings}

\subsubsection{Finding 1: Cross-Lingual Vulnerability is Real}
As presented in Table~\ref{tab:main_results}, baseline models demonstrate notable vulnerability to over-privilege across languages, with Javanese exhibiting elevated over-privilege rates (reaching $33.3\%$ in Qwen-2.5-7B and $25.0\%$ in Llama-3.1-8B). Under transient timeouts on minimal tools, unconstrained baseline models panic-escalate to high-privilege APIs in $56.2\%$ of cases for Qwen-2.5-7B and $43.8\%$ for Llama-3.1-8B ($100.0\%$ in SEA-LION baseline). This confirms that cross-lingual semantic ambiguity and execution failures exacerbate reliance on overly permissive tools.

\subsubsection{Finding 2: Prompt Defenses are Inadequate Under Language Shift}
While adding explicit least-privilege instructions into the system prompt reduces over-privilege in English (e.g., reaching $0.0\%$ in GPT-4o and $8.3\%$ in Qwen and Llama), its efficacy is brittle under language shift. In Indonesian, Llama-3.1-8B's over-privilege rate actually surges to $50.0\%$ despite prompt defenses, and panic escalation remains as high as $53.3\%$. Similarly, Qwen-2.5-7B maintains $16.7\%$ over-privilege in Javanese. Prompt-level guardrails remain fundamentally stochastic and unreliable when transferred across typologically diverse languages.

\subsubsection{Finding 3: Capability-Preserving Verification Enforces Deterministic Safety}
When our deterministic lattice guardrail is active:
\begin{enumerate}
    \item \textbf{Privilege Downgrading:} Across all models and languages, over-privileged tool calls bearing scoped entity identifiers (e.g., student IDs or user accounts) are deterministically intercepted and down-cast to their minimal sufficient equivalents. In Indonesian, our verifier slashes Llama-3.1-8B's over-privilege rate from $50.0\%$ under prompt defense down to $8.3\%$, and reduces SEA-LION's over-privilege rate from $50.0\%$ down to $8.3\%$.
    \item \textbf{Preserved Functional Utility:} Because our lattice indexes tools by explicit functional capability rather than coarse domain labels, the guardrail avoids erroneous cross-capability conversions (maintaining task completion rates between $66.7\%$ and $83.3\%$ across models).
    \item \textbf{Containment of Panic Escalation:} The verifier's fault quarantine significantly blunts transient failure escalation, lowering Llama-3.1-8B's fault escalation from $53.3\%$ to $31.2\%$ and preventing runaway privilege creep when APIs encounter transient faults.
\end{enumerate}

\subsubsection{Finding 4: Negligible Latency Overhead}
While end-to-end API inference across distributed provider backends averaged $1.52\text{s}$ per transaction, the standalone computational overhead of our parameter inspection and lattice resolution engine is strictly sub-millisecond ($\Delta t < 0.02\text{ms}$ per invocation), confirming practical suitability for real-time production deployment.
