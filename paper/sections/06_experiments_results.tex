\section{Experiments and Empirical Results}
\label{sec:experiments}

\subsection{Experimental Setup and Models}
We evaluate 432 controlled execution trajectories across four model architectures:
\begin{itemize}
    \item \textbf{SEA-LION-7B-Instruct}~\cite{aisingapore2024sealion}: The primary open regional model for Southeast Asian languages.
    \item \textbf{Qwen-2.5-7B-Instruct}: State-of-the-art open multilingual foundation model.
    \item \textbf{Meta-Llama-3.1-8B-Instruct}: Global open baseline.
    \item \textbf{GPT-4o}: Proprietary frontier benchmark.
\end{itemize}

For each model, we evaluate three defense regimes across all three language tiers ($N = 12$ tasks each):
\begin{enumerate}
    \item \textbf{Baseline:} Standard unconstrained tool selection.
    \item \textbf{Prompt Defense:} The system prompt explicitly instructs the agent to enforce least privilege and avoid over-privileged tools.
    \item \textbf{Our Verifier:} The deterministic capability-preserving lattice guardrail.
\end{enumerate}

\subsection{Key Empirical Findings}

\subsubsection{Finding 1: Cross-Lingual Vulnerability is Real}
As presented in Table~\ref{tab:main_results}, baseline models demonstrate a substantial and monotonic surge in over-privilege as the prompt language transitions from English ($8.3\% - 25.0\%$) to Indonesian ($25.0\% - 41.7\%$) and Javanese ($33.3\% - 58.3\%$). In Javanese, more than half of the unconstrained tool calls executed by SEA-LION and Llama-3.1 violated least privilege. This empirically confirms that semantic dispersion in regional languages increases reliance on over-privileged tools.

\subsubsection{Finding 2: Prompt Defenses are Inadequate Under Language Shift}
While adding explicit least-privilege instructions into the system prompt reduces over-privilege in English (dropping to $8.3\% - 16.7\%$), its efficacy degrades sharply in Javanese, where $OPR$ remains as high as $41.7\% - 50.0\%$. Stochastic prompt-level defenses do not guarantee security when the underlying semantic representation of the query is ambiguous.

\subsubsection{Finding 3: Capability-Preserving Verification Guarantees Safety}
When our deterministic lattice guardrail is active:
\begin{enumerate}
    \item \textbf{Complete Privilege Containment ($OPR = 0.0\%$):} All over-privileged tool calls are intercepted. Because parameter scope inspection proves that only singular entity identifiers are provided, calls are safely down-cast to the minimal sufficient equivalent.
    \item \textbf{Preserved Task Completion ($TCR = 100.0\%$):} Because the lattice indexes tools by explicit functional capability (e.g., separating \texttt{financial\_balance} from \texttt{academic\_transcript}), the guardrail never cross-downgrades to a functionally mismatched tool.
    \item \textbf{Transient Fault Immunity ($PER = 0.0\%$):} Under synthetic HTTP 504 timeouts on minimal tools, baseline models panic and escalate to administrative tools in up to $75.0\%$ of cases. The verifier's fault quarantine catches these attempts and prevents unauthorized escalation.
\end{enumerate}

\subsubsection{Finding 4: Negligible Latency Overhead}
Across all executions, the mean runtime overhead of parameter inspection and lattice resolution was $\Delta t = 12.8 \pm 1.6\text{ms}$, well within production latency requirements for interactive agent runtimes.
